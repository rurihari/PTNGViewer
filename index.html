PTNGViewer Flatpak repository

Add this repository / このリポジトリを追加:

sudo flatpak remote-add --system --if-not-exists PTNGViewer https://rurihari.github.io/PTNGViewer/PTNGViewer.flatpakrepo
sudo flatpak install PTNGViewer io.github.rurihari.PTNGViewer

Linux Mint のソフトウェアの管理に出すには、システム用 (上) に登録します。 / To make it appear in the Linux Mint Software Manager, add it system-wide (above).
