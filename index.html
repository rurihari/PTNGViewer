PTNGViewer とは / About

フォルダや書庫（ZIP・RAR・7-Zip など）の画像を、見開きや単ページで快適に読める Linux 向けのビューワーです。スライドショー、本棚、しおり、前回の続きから再開、22 言語の表示に対応しています。機能や対応形式、スクリーンショットは GitHub のページにまとめています。

PTNGViewer reads images from folders and archives (ZIP, RAR, 7-Zip and more) as two-page spreads or single pages. Features, supported formats and screenshots are on the GitHub project page.

Flatpak リポジトリ / Flatpak repository

このリポジトリを追加 / Add this repository:

sudo flatpak remote-add --system --if-not-exists PTNGViewer https://rurihari.github.io/PTNGViewer/PTNGViewer.flatpakrepo
sudo flatpak install PTNGViewer io.github.rurihari.PTNGViewer

Linux Mint のソフトウェアの管理に出すには、システム用（上）に登録します。
To make it appear in the Linux Mint Software Manager, add it system-wide (above).

更新は flatpak update で受け取れます。 / Updates are delivered with flatpak update.
